# RAIV Español - PWA pública v10

La aplicación pública no contiene los textos privados de RAIV ni el inventario de cartas de Despliegue. Ambos se importan desde `raiv_datos_privados_v10.json` y permanecen en el dispositivo.

## Cambios de v10
- Nueva pestaña **Despliegue**.
- Inventario privado de 78 cartas físicas: 43 Imperiales y 35 Mercenarias.
- Preparación de grupos iniciales y de reserva.
- Mazo de Despliegue según nivel de amenaza y recompensas de campaña.
- Mano de Despliegue oculta.
- Intento de despliegue en Fase de Estatus, incluyendo envío al fondo si falta amenaza.
- Grupos derrotados no únicos vuelven a la Mano y ésta se baraja.
- Reservas pueden pasar a desplegados.
- Orden izquierda→derecha editable.
- Enlace automático con las Cartas IA cuando se despliega un grupo.
- Las recompensas de Despliegue desbloquean una carta física concreta para la campaña.

Los guardados de v9 se conservan. Para usar la nueva función de Despliegue hay que importar una vez el nuevo archivo privado v10.
