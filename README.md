# RAIV Español - PWA pública v9

La aplicación pública no contiene los textos privados de RAIV. Los datos se
importan desde el archivo privado y permanecen en el dispositivo.

## Cambios de v9
- Nueva pestaña Campaña.
- Creación de campaña con dificultad RAIV.
- Final de misión con actualización automática de Planes Secretos/Ayudas Rebeldes.
- Registro de recompensa Imperial de Despliegue o no de Despliegue.
- Historial de misiones completadas.
- Migración de la partida guardada de v7/v8 sin borrar el estado existente.
- Biblioteca IA visible mediante una lista propia, sin depender del selector nativo de iPad.
- Indicador de guardado más claro y mantenimiento accesible desde él.

El archivo privado `raiv_datos_privados_v7.json` sigue siendo válido.
